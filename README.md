Bootstrap veebileht - Burger Tank (Bootstrap webpage)

1. Mis see on?

See on siis veebileht, mille koostmisel kasutati lisaks HTML-i ja CSS-i ka Boostrapi.

Bootstrap sisaldab jub valmis tehtud klasse, mida saab kasutada veebilehtede lihtsama kaunistamiseks.

2. Miks see veebileht on tehtud?

Veebileht on tehtud selleks, et näidata juba valmis tehtud klasse, mis Bootstrap sisaldab ning kui lihtsaks

see võib veebilehted koostmist teha, võrreldes veebilehe koostmine ilma selleta ning ise klasside koostmine.

3. Mis on siis veebilehe koostmisel kasutati?

Nagu oli juba mainitud, on kasutusele võetud HTML, CSS ning Bootstrap. Bootstrapi kasutamiseks, ma enne koostsin endale package.json faili

kasutades terminalis "npm init -y" ning pärast kasutasin terminalis ka "npm install boostrap" ning sain siis Bootstrapi endale kasutusele

võtta.
